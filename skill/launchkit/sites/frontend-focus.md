# Frontend Focus

Cooperpress's weekly front-end newsletter (761+ issues since 2011), curated by Chris Brandrick and Peter Cooper. It covers HTML, CSS, browser APIs, performance and web platform tools. There is no web form: every issue says "Got a link for us? Reply and tell us." Good fit for front-end dev tools, CSS/JS libraries and browser tech. Not for general SaaS.

## Before you start
- Fit check: the product or article must interest front-end developers (a CSS tool, component library, browser extension for devs, performance tool). Otherwise mark `skipped`.
- Best link is a technical article or a repo/demo page, not a pricing page.
- Pitch goes by email: reply to an issue (the user needs to be subscribed) or write to editor@cooperpress.com (listed on cooperpress.com/contact).

## Field map

| Email part | Limit | Fill with |
|---|---|---|
| To | email | editor@cooperpress.com, or reply to the latest issue |
| Subject | short | "Link for Frontend Focus: <product.name>, <what it does>" |
| Body line 1 | 1 sentence | what it is, from `product.tagline` |
| Body line 2-3 | 2 sentences | the front-end specifics: tech used, browser support, size, open-source status (`product.repo_url`) |
| Link | URL | `product.repo_url`, `links.docs` or a write-up, plus `product.url` |
| Sign-off | name | `founder.name`, `founder.github` |

## Steps
1. Open https://frontendfoc.us/ and skim the latest issue (frontendfoc.us/issues) to match tone. Items are one-paragraph summaries with a linked headline.
2. Write a 60-100 word email per the map.
3. `launchkit draft frontend-focus -` and mark `drafted`. Send only with explicit approval, from the user's own email.

## Make the listing perform
- Write the pitch the way they write items: a plain headline plus one paragraph saying what a developer gets. Editors often reuse that wording.
- Open-source tools and demos with a live playground get picked more than closed products (judging from recent issues).
- Don't pitch the same link to JavaScript Weekly and Node Weekly in the same week; Cooperpress editors share an inbox.

## Gotchas
- Paid route: sponsor slots and 200-character classified ads via cooperpress.com/classifieds or sales@cooperpress.com. Skip at budget 0.
- No attachments in the first email.

## After submitting
- No confirmation is sent. Check the next two Wednesday issues in the archive.

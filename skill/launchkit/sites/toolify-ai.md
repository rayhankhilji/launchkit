# Toolify.ai

A large AI directory with multilingual pages and its own ads system. On 2026-10-12 the submit page showed **only a paid option: $99 one-time**. No free queue was visible on the page or in the FAQ.

## Before you start
- $99 needs the user's approval. Payment is `needs_human`.
- Have `product.name`, `product.url`, and an English `product.description_medium` ready in case you write the info yourself.
- A login page exists (https://www.toolify.ai/login, Google or email and password). The submit page may ask you to sign in before paying. If so, use `submission.preferred_login` only if `submission.allow_account_creation` is true.

## Field map

| Field on the site | Limit / format | Fill with |
|---|---|---|
| Name | text | `product.name` |
| Website URL | URL | `product.url` |
| Choose how to generate tool information | radio | "Generated by Toolify" by default. Pick the manual option only if the user wants to control the copy |
| Manual description (if chosen) | English text | `product.description_medium` |

## Steps
1. Ask the user to approve $99.
2. Open https://www.toolify.ai/submit. Fill Name and Website URL.
3. Pick how info is generated. If manual, paste `product.description_medium` in English.
4. Continue to payment and stop there. Hand off to the user.
5. Screenshot to `.launchkit/evidence/toolify-ai.png`. `launchkit mark toolify-ai needs_human --note '$99 one-time, listed in 48h after payment'`

## Make the listing perform
- The $99 listing includes a permanent page, dofollow links, multiple links, border highlight, an "AI certification" mark, and translated introductions. The translations bring in non-English search traffic, so keep the English text short and literal so it translates well.
- Extra views come only from paid ads (click packs of 500 to 50,000). Skip unless the user asks.
- If you let Toolify generate the text, check it after publication. Generated copy often misreads pricing.

## Gotchas
- `curl` gets 403. Use the browser.
- The FAQ says tools that don't use AI, or are too explicit, get rejected with a full automatic refund.
- "No website yet? Secure your .AI domain" on the page is an upsell. Ignore it.

## After submitting
- Listed within 48 hours after payment and the listing never expires.
- Search toolify.ai for `product.name` and check the category and pricing tags.

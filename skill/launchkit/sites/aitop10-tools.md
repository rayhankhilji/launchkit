# AITop10 Tools

Trilingual AI directory (English, Simplified and Traditional Chinese) from the same network as Woy AI Tools. Free listing requires a backlink on the user's homepage; the paid option is $6.9 and gives 12 dofollow links across 3 languages.

## Before you start
- Free tier: add `<a href="https://aitop10.tools/" target="_blank">AiTop10 Tools</a>` to the user's homepage or footer before submitting. They verify it before review. Check `launch_settings.add_badge_to_site`.
- No login, no uploads (they take the logo and screenshot from the site).
- No adult, gambling or drug sites.

## Field map

Choose **Backlink $0 -> Continue**, then:

| Field on the site | Limit / format | Fill with |
|---|---|---|
| Title | 100 chars | `product.name` (optionally "Name - tagline_short" if under 100) |
| Website URL | URL, 500 chars | `product.url` |
| Description | 160 chars | `product.description_short` |
| Website Introduction | min 300 chars, max 5000 | `product.description_long` structured by their modules: product introduction, key features (`product.key_features`), use cases (`product.use_cases`), pricing (`product.pricing_details`), FAQ (`copy.faq`) |

## Steps
1. Search the site for `product.name`. If listed, mark `live` and stop.
2. Confirm the backlink is live on the user's homepage.
3. Open https://aitop10.tools/submit, click **Continue** under "Backlink $0".
4. Fill the four fields and click **Submit**. Screenshot to `.launchkit/evidence/aitop10-tools.png`.
5. `launchkit mark aitop10-tools submitted --note "free with backlink, 48h-2wk"`

## Make the listing perform
- The introduction field's placeholder asks for modules (intro, features, use cases, pricing, FAQ). Following that structure gives a full profile page, which is translated into Chinese too, so keep sentences simple.
- Pro $6.9 one-time: 12 permanent dofollow links (4 pages x 3 languages), no backlink, indexed within 48 hours. Cheapest paid upgrade in this batch; mention it to the user if they won't add a backlink.

## Gotchas
- The introduction has a 300-character minimum; short copy is rejected.
- Removing the backlink can get the free listing dropped.

## After submitting
- Check the Discover page after a week. Mark `live` with the listing URL.

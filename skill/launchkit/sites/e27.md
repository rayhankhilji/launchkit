# e27

Southeast Asia startup media site with a startup and investor database. Good for products with an Asian market or team. Three ways in: a story pitch via the contact form, a free company profile, and contributor articles.

## Before you start
- Fit: best when `company.country` is in Southeast or East Asia, or the product targets that market. Others can still create a company profile.
- The pitch form accepts a press release upload (doc, docx or pdf, max 2 MB). Export one if the user has it, otherwise skip the upload.
- The company profile (https://e27.co/startup/create/profile) and contributor articles (https://e27.co/contribute/) need an e27 account (email, LinkedIn or Facebook sign-up). Create one only if `submission.allow_account_creation` is true.

## Field map
Contact form: choose "I want to pitch a story or I would like to send a tip to the e27 content team".

| Field on the site | Limit / format | Fill with |
|---|---|---|
| Option | dropdown | "I want to pitch a story or I would like to send a tip to the e27 content team" |
| Category | dropdown | closest to `product.categories[0]` |
| Summarise your tip in one sentence | textarea, required | one-sentence news hook |
| Explain your tip in detail | textarea, required | `copy.press_pitch` adapted, with the Asia angle and links |
| Timeline to be Published | text | embargo date or "any time" |
| Upload press release | doc/docx/pdf, 2 MB max | optional press release |
| Name / email | unconfirmed, likely shown after the option is chosen | `founder.name`, `founder.email` |

Company profile (behind login, fields not confirmed): expect name, logo (`assets.logo_square`), website, location, vertical, description (`product.description_medium`), founders, funding stage (only if in profile).

## Steps
1. Open https://e27.co/contact-us/ and pick the pitch option from "Please Select An Option".
2. Draft the summary and detail text, `launchkit draft e27 -`, mark `drafted`.
3. With `pitch` mode on and user approval: fill the form, upload the release if any, submit, screenshot to `.launchkit/evidence/e27.png`, then `launchkit mark e27 submitted --note "contact form pitch"`.
4. If `form` mode is on too, create the free company profile via **Add Company Profile** and note it in the mark note.

## Make the listing perform
- Funding news has its own page: https://e27.co/startup-funding-news/. Use that for rounds instead of the general pitch.
- e27 runs a large contributor programme. A useful founder essay (lessons, market data from SEA) gets published more often than a product pitch. Draft one from `copy.launch_post_story` if the user wants it.
- A complete company profile makes the startup show up in e27's database searches by investors. Fill every field you can verify.

## Gotchas
- e27 blocks plain HTTP clients, so use the real browser.
- Paid items on the site (PRO subscription, Echelon event tickets, "Work with us" marketing) are not needed for coverage.

## After submitting
- Search e27.co for `product.name`. If the profile is created, link it from the user's press page.

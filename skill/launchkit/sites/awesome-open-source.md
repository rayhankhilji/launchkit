# Awesome Open Source

**No submission path: skip.** The site is live but it's an automated index of GitHub repos (claims 1.5M projects,
7,000 categories). There is no "submit" or "add project" form, and the data looks stale: on 2026-10-12 project
pages showed "most recent commit over 2 years ago" for repos that are committed to daily.

## Before you start
- Nothing to prepare. Projects appear here (if at all) when the index crawls GitHub.

## Field map

| Field on the site | Limit / format | Fill with |
|---|---|---|
| (none) | - | No public submission form exists |

## Steps
1. Search the site for `product.name` or the repo path (`/project/<owner>/<repo>`).
2. If a page exists, `launchkit mark awesome-open-source live --listing-url <url>`.
3. Otherwise `launchkit mark awesome-open-source skipped --note "no submission form, auto-indexed from GitHub"`.

## Make the listing perform
- Out of your control. A public GitHub repo with clear topics and description is the only input.

## Gotchas
- Pages show "Suggest Alternative" and "Edit Category" links, but those are for categorisation, not adding projects.

## After submitting
- Nothing to follow up.

# Startup Digest (Techstars)

Techstars Startup Digest is a set of local and topic newsletters written by volunteer curators. They mostly share startup **events** in a city plus a few reading links. Issues are published on Letterhead (https://read.letterhead.email/techstars, issues seen through September 2026). There is no product submission form. This is a low-yield target unless the founder is running an event or has a strong local angle.

## Before you start
- Decide if there is a fit: a launch event, meetup, webinar or demo day in a city that has a digest, or a founder resource/article. A plain product listing is not what curators share.
- Know `company.city` and `company.country` to find the matching local digest.
- The only official contact is https://www.techstars.com/contact (general Techstars form). Curator contact details are not public on the page.

## Field map

No submission form. If writing to a curator or via the contact form:

| Part | Limit / format | Fill with |
|---|---|---|
| Which digest | city or topic | match `company.city`, otherwise the closest topic digest on Letterhead |
| Subject | short | event name + date, or "Founder resource: " + `product.name` |
| Body | under 120 words | event details, or `copy.press_pitch` cut down to what helps local founders |
| Link | URL | event page, or `product.url` |
| Name / email | text | `founder.name`, `submission.email` |

## Steps
1. Open https://read.letterhead.email/techstars and look for a digest that matches `company.city` or the product's topic. Read one recent issue to see the format.
2. If there is a matching event or resource, draft a short note from `copy.press_pitch` with the event details first.
3. `launchkit draft startup-digest-techstars -` and mark `drafted` with "no public form; contact curator or techstars.com/contact".
4. If there is no event or local fit, mark `skipped` ("events newsletter, no fit").

## Make the listing perform
- Curators pick events and practical founder resources. Lead with what a local founder gets (a free workshop, a template, a discount for attendees), not with the product.
- Send event pitches 2-3 weeks before the date so they land in a weekly issue.
- A free resource from the product (guide, calculator, template) fits better than the product page.

## Gotchas
- The "Learn more" link on the page is for becoming a curator, not for submitting content.
- Some local digests are dormant; check the date of the latest issue before pitching.
- Don't use the Techstars accelerator application (apply.techstars.com) for this.

## After submitting
- Watch the matching digest on Letterhead for the next two issues. If featured, mark `submitted` with the issue link.

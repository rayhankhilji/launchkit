# Web Tools Weekly

A weekly newsletter for front-end developers by Louis Lazaris, about 15.7k subscribers (31% open rate), sent every Thursday morning EST. Free submissions go by DM, not a form. Accepts libraries, frameworks, plugins, scripts, web/desktop/mobile apps, APIs and editors; no articles or tutorials.

## Before you start
- Fit check: the product must be useful to web developers, programmers or designers. Productivity tools now go to his other newsletter, Tech Productivity (https://techproductivity.co/), using the same DM route.
- Channel: DM **@LouisLazaris on X** (DMs open) or chat **@LouisLazaris.com on Bluesky**. Replying to an issue email also works for subscribers. The contact form on /contact is for advertising only.
- DMs go from the user's own account. Draft only unless the user approves and `allow_social_posting` allows it.

## Field map

No form. The DM should contain:

| Part | Limit / format | Fill with |
|---|---|---|
| Opening | 1 line | "Built a tool that might fit Web Tools Weekly:" |
| Name + link | text + URL | `product.name`, `product.url` (or `product.repo_url` if open source) |
| What it does | 1 sentence | `product.description_short`, in developer terms |
| Pricing | few words | from `product.pricing_model` (free / open source matters here) |
| Sign-off | name | `founder.name` |

## Steps
1. Open https://webtoolsweekly.com/submit and confirm the DM handles are still listed.
2. Write a DM under 60 words from the map. No attachments, no pitch deck.
3. `launchkit draft web-tools-weekly -` with the DM text and target handle, then mark `drafted`.
4. Only with user approval: send from the user's X or Bluesky account and mark `submitted` with "DM sent to @LouisLazaris".

## Make the listing perform
- Issues are grouped by category with one-line descriptions. Write the sentence so it can be pasted as is.
- Free and open source tools get picked most. For a paid SaaS, mention the free tier.
- Classified Listing is $10 (single link, "Commercial Apps" section) if the user wants a guaranteed slot on a tiny budget. Other ads: Text Link Combo $30, Middle Image Ad $50, Top Ad Combo $175, Paid Product Review $375. Book through https://webtoolsweekly.com/contact (form fields: name, email, URL to advertise, ad plan, comments max 400 chars).

## Gotchas
- Articles and tutorials are rejected outright.
- Don't use the advertising contact form for a free submission.
- Ad Swap (free) is only for newsletters with 3,000+ subscribers.

## After submitting
- Check the archive at https://webtoolsweekly.com/archive on the next Thursdays. If included, mark `submitted` with the issue URL.
